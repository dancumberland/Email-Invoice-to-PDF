# LLM Brand Voice Training Template
Version 1.0

## Purpose of This Template
This template is designed specifically for training Large Language Models (LLMs) to accurately replicate a brand's voice, style, and communication patterns. The complete training document should be split into multiple files to prevent context truncation and ensure comprehensive coverage.

## Document Organization
The complete brand voice training document is split into the following files:

1. `01_executive_summary.md`
   - Document purpose and objectives
   - How to use the training files
   - Success metrics
   - Document navigation

2. `02_brand_foundation.md`
   - Core brand identity
   - Voice characteristics
   - Brand evolution
   - Personality dimensions

3. `03_linguistic_patterns.md`
   - Vocabulary analysis
   - Sentence structures
   - Paragraph patterns
   - Transition techniques

4. `04_content_types.md`
   - Platform-specific voice adaptations
   - Content type specifications
   - Format-specific guidelines
   - Cross-platform consistency

5. `05_audience_understanding.md`
   - Audience profiles
   - Pain points and aspirations
   - Communication preferences
   - Engagement patterns

6. `06_messaging_framework.md`
   - Core messages
   - Value propositions
   - Key themes
   - Message hierarchy

7. `07_storytelling_elements.md`
   - Narrative structures
   - Story patterns
   - Example usage
   - Personal story integration

8. `08_technical_elements.md`
   - Grammar preferences
   - Punctuation patterns
   - Formatting standards
   - Technical specifications

9. `09_brand_language.md`
   - Approved terminology
   - Prohibited language
   - Industry jargon usage
   - Abbreviation guidelines

10. `10_training_examples.md`
    - Before/after examples
    - Case studies
    - Success scenarios
    - Failure scenarios

## Instructions for LLMs

### Document Processing
1. Process each file in numerical order
2. Cross-reference between files when necessary
3. Apply learnings hierarchically, with core brand elements taking precedence
4. Use examples as validation for generated content

### Quality Control
1. Verify each generated piece against:
   - Core brand attributes
   - Linguistic patterns
   - Content type specifications
   - Audience appropriateness

2. Apply multi-step verification:
   - Pattern matching
   - Tone consistency
   - Message alignment
   - Technical accuracy

### Implementation Notes
- Always prioritize brand voice consistency over creative variation
- When in doubt, refer to examples rather than innovating
- Maintain professional boundaries while incorporating personal elements
- Respect brand evolution stages and adapt accordingly

## Usage Instructions
Each subsequent file contains detailed instructions and examples for its specific focus area. Process all files before attempting to generate brand-aligned content. Regular reference and validation against these documents will ensure consistent, accurate brand voice replication.
