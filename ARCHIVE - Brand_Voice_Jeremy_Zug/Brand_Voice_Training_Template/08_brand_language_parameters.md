   ```
   1. Growth Terms
      - Approved: bloom, nurture, cultivate, flourish
   ```

## Technical Language Guidelines

### Grammar and Style

1. Sentence Construction
   ```
   Rules:
   1. Length Variation
      - Short: Impact statements
      - Medium: Teaching points
      - Long: Story development
   
   2. Structure Patterns
      - Active voice primary
      - Personal pronouns
      - Direct address
      - Inclusive language
   
   Example:
   Weak: "Success is achieved through consistent action."
   Strong: "Your growth unfolds through consistent, aligned action."
   ```

2. Punctuation Usage
   ```
   Guidelines:
   1. Ellipsis (...)
      - Reflection moments
      - Thought pauses
      - Story transitions
      - Emotional space
   
   2. Em Dash (—)
      - Emphasis points
      - Thought breaks
      - Impact moments
      - Connection bridges
   
   3. Parentheses ()
      - Additional context
      - Gentle asides
      - Quick definitions
      - Subtle humor
   ```

3. Formatting Standards
   ```
   Elements:
   1. Emphasis
      - Bold: Key points
      - Italic: Subtle emphasis
      - Quotes: Direct speech
      - Bullets: List items
   
   2. Structure
      - Paragraphs: 2-4 sentences
      - Sections: Clear breaks
      - Headers: Hierarchical
      - Lists: Organized points
   ```

1. Tone Check
   ```
   Elements:
   - Warmth level
   - Professional balance
   - Personal connection
   - Emotional resonance
   
   Checklist:
   □ Maintains warmth without losing professionalism
   □ Balances personal and professional
   □ Creates emotional connection
   □ Preserves brand authority
   ```

2. Language Check
   ```
   Elements:
   ```
