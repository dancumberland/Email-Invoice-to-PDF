## Special Instructions

### Pattern Recognition

1. Voice Pattern Identification
   ```
   Process Requirements:
   - Analyze all brand content
   - Document exact patterns
   - Note variations
   - Record context
   
   Example:
   Don't just note "warm tone"
   Instead document exact pattern:
   "Opens with personal observation, transitions to teaching through nature metaphor, closes with invitation to reflect"
   ```

2. Story Pattern Documentation
   ```
   Documentation Requirements:
   - Record full story structures
   - Note transition points
   - Document metaphor usage
   - Include timing elements
   
   Example:
   Don't just note "uses stories"
   Instead document exact pattern:
   "Begins with morning observation, connects to client experience, extracts teaching point, applies to reader's journey"
   ```

3. Language Pattern Recording
   ```
   Detail Requirements:
   - Document exact phrases
   - Note context usage
   - Record variations
   - Include timing
   
   Example:
   Don't just note "uses nature metaphors"
   Instead document exact pattern:
   "Opens with specific nature observation (frost, garden, sunrise), connects to growth principle, applies to client journey"
   ```
